# 本文

概要

父サンデーサイレンス、母ウインドインハーヘア、母父アルザオ。父はアメリカ生まれで、日本で13年続けて総合リーディングサイアーになった種牡馬。母はアイルランド生まれの欧州の中長距離馬で、4歳夏にドイツの芝2400メートルのG1アラルポカルを勝ち、英オークスで2着している。牝系は英1000ギニーと仏オークスを勝ったハイクレアにさかのぼる欧州のクラシック牝系。5代以内に父側と母側で重なる祖先は無く、アメリカの父系と欧州の母系を並べた外向きの配合。素地としては芝の中距離を軸に、2400メートルまで無理なく届く側に置く。

母と牝系

母ウインドインハーヘアは13戦3勝で、4歳夏に牡馬混合のアラルポカル（独G1・芝2400メートル）を勝っている。3歳では英オークス（芝約2400メートル）2着、愛オークス4着、4歳でヨークシャーオークス3着。芝2400メートルで欧州の最上級と繰り返し戦えた牝馬で、これがこの馬の血統でいちばん近く、いちばん確かな材料になる。

母の子はこの馬を除いて15頭。走った13頭のうち8頭が勝ち上がっている。上のクラスに届いたのは、全兄ブラックタイド（2001年産・牡・父サンデーサイレンス）が22戦3勝でスプリングステークス（G2・芝1800メートル）勝ち、半姉ヴェイルオブアヴァロン（1997年産・牝・父サンダーガルチ）が19戦7勝でアメリカの芝のG3勝ち、半姉レディブロンド（1998年産・牝・父シーキングザゴールド）が6戦5勝でスプリンターズステークス4着。ほかに全弟オンファイア（2003年産・牡・父サンデーサイレンス）が3戦1勝、半弟ニュービギニング（2004年産・牡・父アグネスタキオン）が39戦3勝、半弟モンドシャルナが43戦4勝。

きょうだいが勝ち負けした条件は、短距離から中距離まで散らばっている。相手の種牡馬もシーキングザゴールド、デインヒル、アグネスタキオンと替わっていて、同じ条件で比べられるきょうだいはいない。きょうだいから距離の上限を決めることはしない。ここから読めるのは、この母が短い距離から中距離まで幅のある子を出しているということまで。

牝系がどこまで伸びるかは、レディブロンドの枝がはっきり示している。娘ラドラーダ（父シンボリクリスエス）からは日本ダービーと天皇賞（秋）を勝ったレイデオロが出ており、日本の芝2000から2400メートルの最上級に届いている。一方でレディブロンドの子ゴルトブリッツ（父スペシャルウィーク）はダートのG1帝王賞を勝っている。同じ牝系から芝の中長距離とダートの中距離の両方に上級馬が出ているので、牝系からダートを消す材料は無い。

母の母バーグクレア（父バステッド）自身は6戦1勝だが、母のほかに半姉インヴァイトを出し、その子ウインクリューガーがNHKマイルカップ（芝1600メートル）を勝っている。3代母ハイクレアは英1000ギニーと仏オークスを勝った牝馬で、子にプリンセスオブウェールズステークスのミルフォード、娘ハイトオブファッションからは英ダービーと英2000ギニーのナシュワン、アンフワイン、ネイエフが出ている。マイルのクラシックから芝2400メートルの最上級までが同じ枝に並ぶ牝系で、速さだけにも持久力だけにも寄っていない。

産駒の傾向

父サンデーサイレンスの子は1,535頭で、この馬を除いても1,534頭。日本の総合リーディングサイアーを13年続けて獲り、多い年には293頭が出走して105頭が勝ち、197勝を挙げている。条件別の勝率まで揃った形では確かめられていないが、幅を読むには足りる規模。

この馬を除いても、産駒は距離でも脚質でも一方向に寄らない。芝の中距離のクラシックにスペシャルウィーク、ネオユニヴァース、牝馬三冠のスティルインラブ。芝2000から2500メートルの古馬の最上級にゼンノロブロイ。長い距離に菊花賞と天皇賞（春）のマンハッタンカフェ、海外の芝2400メートル級を勝ったステイゴールド。マイルにダイワメジャー、ハットトリック。短距離にデュランダル、ビリーヴ。前で速さを持続する形にサイレンススズカ。終いの切れで差す形も、前で押し切る形も上級で成立している。父の産駒の傾向からは距離も脚質も絞れないので、絞るのは母系の側になる。

馬場は芝が主戦場だが、ダートを否定する産駒ではない。ゴールドアリュールがフェブラリーステークスなどダートのG1を複数勝っており、ほかにもダートの重賞を勝った産駒がいる。数の上では芝に偏るが、産駒の傾向からダートが向かないとは言えない。

サンデーサイレンスはノーザンダンサー系の牝馬との組み合わせでとくに結果を出したとされる。母の父アルザオはリファールを通じたノーザンダンサー系なので、この馬はその型に入る。ただし、うまくいった配合の型に入っていることは、個体の適性を決める材料ではない。

母父と配合

母父アルザオはリファール産駒で、自身は2歳で8から9ハロン、3歳で9ハロンのリステッド、4歳で12ハロンのG3を勝っている。若い時期から使える速さと、距離を延ばしても保つ幅の両方を持った馬。

種牡馬としての子は、短距離のG1を勝った馬から、マイルG1のセカンドセット、芝2000メートルのG1を連勝したアルボラーダ、英オークスのシャータッシュ、愛オークスのウィノナ、ドイツの芝2400メートル級を勝ったアルバノヴァ、フランスの長距離G1ロワイヤルオーク賞のアルカサルまで幅がある。短距離から3000メートル級まで出しているので、母父からも距離を一点に絞る材料は出てこない。牝馬の活躍が目立ち、母の父としても実績を残した。

母の側はさらに、バーグクレアの父バステッド、その父クレペロ、3代母ハイクレアの母系と、欧州の芝の中長距離を支えた血が続く。父の側が距離も脚質も広く開いているのに対して、母の側は中長距離の持久力の方へ寄っている。父から幅、母から持久力を受け取る、役割の分かれた配合とみる。

系統とクロス

父系はサンデーサイレンス系（ヘイロー系）。母の父はリファールを通じたノーザンダンサー系で、母の母の父バステッドはブランドフォード系。

5代以内に父側と母側で重なる祖先は無い。6代まで広げると、ターントゥが父側4代（ヘイルトゥリーズンの父）と母側6代（サーアイヴァーの父サーゲイロードの父）に、アルマームードが父側4代（コスマーの母）と母側6代（ナタルマの母）に現れる。さらに6代目どうしでは、父側のロイヤルチャージャーと母側のニアークティックからニアーコが重なる。いずれも遠く、血量は小さい。

近い代で血を重ねて特定の性質を狙った配合ではないので、クロスから読める性質は薄い。判断の柱には据えず、血量そのものから能力を言うこともしない。

適性の素地

距離は、芝の中距離を軸に2400メートルまで届く素地とみる。直接の根拠は母自身の芝2400メートルのG1勝ちと英オークス2着で、これがいちばん近い血の実績。牝系側にも仏オークスのハイクレア、日本の芝2400メートルの最上級に届いたレイデオロがいる。3000メートル以上は、父の産駒に菊花賞と天皇賞（春）を勝った馬がいるので否定する材料は無い。母の父の子にも長距離のG1を勝った馬がいる。ただし母とその牝系には直接の実例が見当たらず、2400メートルまでのような近い血の根拠は無い。逆にマイル以下でも、半姉レディブロンドがスプリンターズステークスで4着まで走っており、短い距離の血は入っている。芝2000メートル前後で流れが締まった競馬に対応できず、マイル以下でしか力を出せないようなら、母系の中長距離を重く見たこの読みは外れになる。

速さの出し方は、片方に決めない。父の産駒には終いの切れで差す形も、前で長く脚を使う形も上級にある。母系は欧州の芝2400メートルで、上がりの速さより長く脚を使う側。一方で母父アルザオと半姉レディブロンドは速さの側の血。テンから流れて上がりのかかる決着でも、緩んで上がりだけの決着でも、どちらか片方でしか通用しない素地ではない。どちらがより得意かまでは血統からは決まらない。

位置取りは材料が薄い。父の産駒には逃げて押し切る馬から後ろから差す馬まで上級におり、位置取りは母系と個体で決まっている。母系からも位置取りを決める材料は出てこない。

馬場は芝が第一候補。母、母の母の枝、3代母の枝の実績はいずれも欧州と日本の芝で、父の産駒も芝が主戦場。母が欧州で走った馬なので、洋芝と時計のかかる馬場には対応する側の血が入る。日本の野芝の速い決着については、父の産駒に上級馬が揃っている。ダートは、父の産駒にG1級がおり、牝系にも帝王賞を勝ったゴルトブリッツがいるので可能性は消えないが、ダートを第一候補にする材料も無い。道悪については直接の材料が無い。

コースの形は材料が薄い。母と牝系は欧州の起伏のあるコースと直線の長いコース、父の産駒は日本のどの競馬場でも結果を出している。小回りや急坂について、特定の形を最適とする材料は無い。

気性は材料が無い。母、母の母、きょうだいについて、折り合いやテンションをたどれる話が見当たらない。

成長の型は、早い時期から使えて古馬まで保つ側とみる。父の産駒は2歳の重賞から古馬のG1まで幅があり、母系ではハイトオブファッションの枝が2歳戦から英クラシックまで並ぶ。きょうだいでも全兄ブラックタイドが3歳春のG2を勝っている。晩成に寄せる材料も、早い時期だけで終わる材料も無い。3歳のクラシックの時期にまったく形にならず、古馬になってから一変するようなら、この読みとは違う。

体質は決められない。きょうだいの出走の数は、モンドシャルナの43戦、ニュービギニングの39戦、ブラックタイドの22戦、ヴェイルオブアヴァロンの19戦から、半姉レディブロンドの6戦、全弟オンファイアの3戦まで開きがあり、母自身は13戦。長く使えた例も早く止まった例も同じ母から出ているので、丈夫さも、使える間隔も、季節も、血統から言える材料が無い。

# 調べた範囲

父系・母系とも5代まで確認し、クロスを見るために一部を6代まで（父側はターントゥの父ロイヤルチャージャーとアルマームード、母側はサーアイヴァーの父サーゲイロード、ノーザンダンサーの父ニアークティックと母ナタルマまで）。母の子はこの馬を含めて16頭、除くと15頭で、うち走った13頭の戦績まで。半姉レディブロンドの枝は娘ラドラーダ、子ゴルトブリッツ、孫レイデオロまで。母の母バーグクレアの子は母と半姉インヴァイト、その子ウインクリューガーまで。3代母ハイクレアの枝は子ミルフォードとハイトオブファッション、その子ナシュワン、アンフワイン、ネイエフまで。父の子は1,535頭で、この馬を除くと1,534頭。父の子について見たのは重賞級の実例と、年間の出走頭数・勝馬数・勝ち数の規模まで。芝とダートの別や距離帯ごとの勝率は確認していない。母父アルザオの子も重賞級の実例までで、条件別の成績は確認していない。
