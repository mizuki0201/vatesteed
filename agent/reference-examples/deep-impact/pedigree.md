# 本文

## 概要

父サンデーサイレンス、母ウインドインハーヘア、母父アルザオ。父はアメリカ生まれで、日本で13年続けて総合リーディングサイアーになり、芝の短距離から長距離、逃げから追い込みまで異なる型のG1馬を出した。母は欧州で13戦3勝、ドイツの芝2400メートルのG1アラルポカルを勝ち、英オークスで2着。牝系は英1000ギニーと仏オークスを勝ったハイクレアにさかのぼり、欧州のクラシック、短距離、日本の芝中長距離、ダート中距離へ枝を広げている。

配合全体では、父から日本の速い芝に対応する速さと脚の使い方の幅、母から芝2400メートル級を最後まで保つ持久力、母父アルザオから若い時期の速さと中長距離への幅を受ける形になる。近い代に強いクロスを置かず、アメリカの父系と欧州の母系の異なる性質を組み合わせた構成。適性の中心は芝2000メートル前後から2400メートルで、流れの中で脚をため、直線で速い脚を使いながら最後まで保つ素地が厚い。

## 母と牝系

母ウインドインハーヘアは13戦3勝。3歳時に英オークス2着、愛オークス4着、4歳時には牡馬混合のアラルポカルを勝ち、ヨークシャーオークスでも3着に入った。芝2400メートルの欧州最上級で複数回上位に入り、牝馬限定戦だけでなく牡馬相手のG1も勝った実績は、この血統で距離と持久力を読む最も近い根拠になる。3歳春から4歳まで水準を保った競走歴も、早い時期の完成だけに寄らず、古馬期まで能力を保つ牝系の一例になる。

母の子はこの馬を除いて15頭で、出走した13頭のうち8頭が勝ち上がった。全兄ブラックタイドは22戦3勝で、3歳春のスプリングステークスを勝った。半姉ヴェイルオブアヴァロンは父サンダーガルチで19戦7勝、アメリカの芝重賞を勝利。半姉レディブロンドは父シーキングザゴールドで6戦5勝、芝1200メートルのスプリンターズステークスで4着。全弟オンファイアは3戦1勝、半弟ニュービギニングは父アグネスタキオンで39戦3勝、半弟モンドシャルナは43戦4勝だった。

きょうだいは、同じサンデーサイレンスとの配合から芝1800メートルの重賞馬が出た一方、シーキングザゴールドとの配合では芝1200メートルの速さ、サンダーガルチとの配合ではアメリカ芝で連勝を重ねる型が出た。母ウインドインハーヘアが持つ中長距離の持久力を土台に、配合相手の性質によって距離と速さの出し方が大きく動いている。勝ち上がり8頭という厚みと、父が替わっても複数の条件で上級馬を出した実績から、母は特定の距離だけを強く伝えるより、相手の種牡馬の特徴を生かしながら競走能力を伝えた繁殖牝馬と読める。

半姉レディブロンドの枝は、この牝系が日本でどう展開したかを示す。娘ラドラーダは父シンボリクリスエスで、その子レイデオロが日本ダービーと天皇賞（秋）を勝った。レイデオロは芝2000メートルから2400メートルの最上級で結果を残し、レディブロンド自身の短距離実績とは異なる中長距離型になった。同じレディブロンドの子ゴルトブリッツは父スペシャルウィークで、ダート2000メートルの帝王賞を勝った。短距離を得意としたレディブロンドの枝から、配合相手に応じて芝中長距離とダート中距離のG1馬が分かれており、牝系には速さを保ちながら馬場と距離の違いを受け入れる幅がある。

母の母バーグクレアは6戦1勝。半姉インヴァイトの子ウインクリューガーはNHKマイルカップを勝ち、日本の芝1600メートルで速さを示した。3代母ハイクレアは英1000ギニーと仏オークスを勝ち、マイルの速さとクラシック距離の持久力を同じ馬で示した。ハイクレアの子にはプリンセスオブウェールズステークスを勝ったミルフォードがいる。娘ハイトオブファッションの枝からは、英2000ギニーと英ダービーを勝ったナシュワン、芝中長距離で種牡馬実績を残したアンフワイン、英インターナショナルステークスやプリンスオブウェールズステークスを勝ったネイエフが出た。

ハイクレアからウインドインハーヘアまで、マイルのクラシックに届く速さと、芝2400メートル級を保つ持久力が世代を越えて現れている。短距離のレディブロンド、マイルのウインクリューガー、中距離のネイエフ、2400メートルのナシュワンとレイデオロが同じ牝系に並ぶため、距離の長さだけでなく、配合相手によって速さと持久力の配分を変えられることがこの牝系の特徴になる。

## 産駒の傾向

父サンデーサイレンスの子は1,535頭で、この馬を除いても1,534頭。日本の総合リーディングサイアーを13年続けて獲り、多い年には293頭が出走して105頭が勝ち、197勝を挙げた。大きな母数の中から、距離、馬場、位置取り、脚の使い方が異なる上級馬を継続して出しており、父から受ける中心は特定条件への狭い適性より、芝で速い脚を競走能力へ変える力と、母系の特徴を生かす幅にある。

芝の中距離ではスペシャルウィーク、ネオユニヴァース、牝馬三冠のスティルインラブ、芝2000メートルから2500メートルではゼンノロブロイがG1を勝った。長距離ではマンハッタンカフェが菊花賞と天皇賞（春）、ステイゴールドが海外の芝2400メートル級を勝利。マイルではダイワメジャーとハットトリック、短距離ではデュランダルとビリーヴがG1へ届いた。サイレンススズカのように前方から速さを持続する馬と、デュランダルのように後方から終いの速さを使う馬の両方を出している。

この分布から、父は距離や位置を一方向へ固定するより、母系が持つ距離と持久力へ、日本の芝で必要な速さ、加速、競走のしやすさを加える種牡馬と読める。ウインドインハーヘアの芝2400メートル実績と組み合わさるこの配合では、父の短距離馬や逃げ馬の例より、中距離以上で速い脚を長く保ったスペシャルウィーク、ゼンノロブロイ、マンハッタンカフェ、ステイゴールドの側が母系の性質と重なる。

芝を主戦場としながら、ゴールドアリュールはフェブラリーステークスなどダートのG1を複数勝った。父からはダートで使う力も伝わっているが、この馬では母と牝系の上級実績が芝に厚く、配合の中心は芝中長距離に置かれる。レディブロンドの枝からゴルトブリッツが出たことまで合わせると、ダートの力は牝系の一部にも現れており、芝向きの構成の中に馬場対応の幅も含む。

## 母父と配合

母父アルザオはリファール産駒。2歳時に8から9ハロン、3歳時に9ハロンのリステッド、4歳時に12ハロンのG3を勝った。若い時期にマイル前後の速さを使い、成長とともに2400メートルまで勝ち距離を延ばした競走歴で、早期の速さと中長距離の持久力を同時に持つ。

種牡馬としては、短距離G1馬、マイルG1のセカンドセット、芝2000メートルのG1を連勝したアルボラーダ、英オークスのシャータッシュ、愛オークスのウィノナ、ドイツの芝2400メートル級を勝ったアルバノヴァ、フランスの長距離G1ロワイヤルオーク賞を勝ったアルカサルを出した。短距離から3000メートル級まで上級馬が分布し、特に牝馬の活躍が目立つ。母の父としても、牝系の中長距離能力へ早い時期の速さを加える役割を担った。

サンデーサイレンスはノーザンダンサー系の牝馬との組み合わせから多くの上級馬を出し、アルザオはリファールを通じたノーザンダンサー系にあたる。この配合では、サンデーサイレンスのヘイロー系が持つ速さと、アルザオのノーザンダンサー系が持つ中長距離への幅が組み合わさる。母の母の父バステッド、その父クレペロ、ハイクレアへ続く欧州中長距離の血も母側に重なり、父の速さを母側の持久力で支える構成になる。

## 系統とクロス

父系はサンデーサイレンスを通じたヘイロー系。母父アルザオはリファールを通じたノーザンダンサー系で、母の母の父バステッドはブランドフォード系。父側はアメリカの速さ、母側は欧州の中長距離と、近い世代で異なる系統を組み合わせている。

5代以内に父側と母側で重なる祖先は無い。6代まで広げると、ターントゥが父側4代と母側6代、アルマームードが父側4代と母側6代に現れる。さらに父側のロイヤルチャージャーと母側のニアークティックを通じてニアーコへつながる。いずれも遠い世代の重なりで、配合の中心は一つの祖先を強く重ねることより、サンデーサイレンスとウインドインハーヘアの異なる性質を組み合わせることにある。

ターントゥとアルマームードは父側の速さの形成に関わる祖先で、母側ではサーアイヴァーとノーザンダンサーの枝を通じて遠く重なる。この遠い共通部分を土台にしながら、近い世代ではヘイロー、リファール、バステッドが分かれているため、同じ速さだけを重ねる形ではなく、父の加速力、母父の距離の幅、牝系の持久力を並べた配合と読める。

## 適性の素地

距離は芝2000メートル前後を中心に2400メートルまでが厚い。母自身が芝2400メートルのG1を勝ち、英オークス2着。3代母ハイクレアは仏オークス、牝系のレイデオロは日本ダービーを勝った。父の子にもスペシャルウィーク、ネオユニヴァース、ゼンノロブロイ、ステイゴールドがいて、父母の両側で芝2000メートルから2400メートルの最上級実績が重なる。3000メートル級は父のマンハッタンカフェと母父アルザオの子アルカサルが支え、長距離へ延びても持久力を供給できる構成。ただし配合で最も近い母の実績が2400メートルに集中するため、中心は超長距離より中長距離に置かれる。

速さの出し方は、直線の一瞬だけに寄るより、加速してから速い脚を保つ形が中心になる。父の子には終いの鋭さで差す馬と、前方から長く脚を使う馬が両方いる。母ウインドインハーヘアとハイクレアの枝は欧州の中長距離で持続力を示し、母父アルザオと半姉レディブロンドの枝はマイル以下にも対応する速さを加える。中長距離の持久力だけで押す配合ではなく、緩い流れから速い上がりへ切り替わる競馬と、早めに動いて長く速さを保つ競馬の双方へつながる。

馬場は芝が中心になる。母、バーグクレアの枝、ハイクレアの枝は欧州と日本の芝で上級実績を重ね、父の代表馬も芝の各距離に広がる。母がドイツとイギリスの芝2400メートルで実績を残したことは、時計や起伏の異なる芝でも持久力を保った直接的な根拠になる。父の子は日本の速い芝で多数のG1を勝っており、欧州型の持久力だけに偏らず、日本の速い決着へ対応する速さも配合に入る。ダートでは父のゴールドアリュールと牝系のゴルトブリッツがG1へ届いているため、芝中長距離を中心としながら、配合相手や個体によってダート中距離へ展開する力も含む。

成長の型は、3歳春のクラシック期から古馬まで能力を保つ側に置く。母は3歳の英オークスで2着し、4歳で牡馬混合G1を勝利。全兄ブラックタイドは3歳春に重賞を勝ち、父の子は2歳重賞、3歳クラシック、古馬G1の各時期で上級馬を出した。ハイクレアの枝も2歳からクラシック、古馬の中長距離へ実績が連なる。早い時期の速さを母父アルザオと父から受け、母と牝系の持久力が古馬期まで支えるため、クラシック期に形を作り、その後も中長距離で能力を伸ばせる構成になる。

この血統で最も強く重なるのは、芝中長距離の持久力に、速い脚へ切り替える能力を足した点である。父の広い産駒分布のうち母系と一致する中長距離型、母自身の芝2400メートル、ハイクレアから続くマイルとクラシック距離の幅、母父アルザオの早期の速さと距離延長が同じ方向を向く。芝2000メートルから2400メートルで、流れに応じて速さを出し、終盤まで保つ競馬が、この配合の事実から最も厚く読める適性になる。

# 調べた範囲

父系・母系とも5代まで確認し、クロスを見るため一部を6代まで確認。母の子はこの馬を含めて16頭、除くと15頭で、出走した13頭の戦績を確認。半姉レディブロンドの枝は娘ラドラーダ、子ゴルトブリッツ、孫レイデオロまで。母の母バーグクレアの枝は母と半姉インヴァイト、その子ウインクリューガーまで。3代母ハイクレアの枝は子ミルフォードとハイトオブファッション、その子ナシュワン、アンフワイン、ネイエフまで。父の子は1,535頭で、この馬を除くと1,534頭。父と母父の子は重賞級の実例と年間の出走頭数・勝馬数・勝ち数を確認。
