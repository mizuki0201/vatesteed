# 入れたメモを取り込む

**外で見かけた話を確かめて、行き先を決めるところまでを通す。** 判断の根拠は
[docs/agent-design.md のメモの取り込み](../../../docs/agent-design.md#メモの取り込み2026-08-22-決定)。

メモは `/dashboard/record-memo` から入る。**入っているのは評価ではなく、まだ確かめていない
材料。** 分類も宛先も付いていないので、ここで決める。

**人間が居るときにやる。** 裏で流さない。メモは人間が書いたものなので、そこから起こした評価は
AI 単独の産物ではない。書き込む `author` は **対話**。

## 1. 待っているものを引く

```
pnpm db:query "SELECT id, body, source, status, created_at FROM memos WHERE status = ANY($1::text[]) ORDER BY created_at ASC" --params '[["未処理","保留"]]'
```

**古いものから1つずつ。** まとめて処理しない。

予想の一部として呼ばれたときは、**そのレースに関係するものだけ**を見る。関係しないものは
そのまま残す。

## 2. 何についての話かを読む

**メモの文面だけで決めない。** 誰の話か、どのレースの話かが書かれていないことの方が多い。
DB を引いて、指している対象を特定する。特定できなければ 4 の保留へ。

## 3. 裏を取る

蓄積と突き合わせて、足りなければ調べる。**[裏取りの基準](../../../docs/agent-design.md#裏取りの基準)に
従う。2回試して駄目ならそこで止める。**

- **禁止リストに載っているドメインは見ない**（[docs/compliance.md](../../../docs/compliance.md)）
- **取れなかったことも書く。** 「調べたが確かめられなかった」は材料になる
- **メモと食い違ったら、食い違いと理由を人間に出す。** 黙って見送らない
  （[docs/product.md](../../../docs/product.md#人間の読みは勝手に上書きしない)）

## 4. 行き先を決めて書く

| メモの中身 | 行き先 | 通す決まり |
| --- | --- | --- |
| 陣営・騎手が述べたこと | `entry_comments` | **対象の出走が DB にあること。** 無ければ保留 |
| ある出走で何が起きたか | `entry_notes` | |
| 馬についての話 | `horse_notes` | **AI が単独で書かない。** 対話で決める |
| 騎手・厩舎・コース・血統の話 | 各 `*_notes` | 人間が書いた行を塗り替えるなら合意を取る |
| Vatesteed 自体の話 | `docs/tasks/` | `task-management` スキル |
| 裏が取れない / 宛先が無い | どこにも書かない | `status` を保留にする |

- **評価を書くときは、その対象の分析する役を呼ぶ。** メモの文面をそのまま `*_notes` に
  貼らない。既にある評価と噛み合う形に読み直す
- **`entry_comments` を登録するのはオーケストレーター**（[docs/agent-design.md](../../../docs/agent-design.md#登録するのはオーケストレーター)）
- **宛先が無いことは、よくある。** 外で見かける話の多くは今週のレースの話で、その出走が
  DB に入るのは枠順が確定してから。**保留にして待たせる**のが正しい

## 5. メモを閉じる

```
pnpm db:query "UPDATE memos SET status = $2, verification = $3, outcome = $4 WHERE id = $1" --params '[12,"取り込み済み","調教のことは他でも同じ話が出ていた","horse_notes を更新"]'
```

- `verification` に**確かめたこと**、`outcome` に**どこへ何を書いたか**を入れる
- **見送るときも `outcome` に理由を書く。** 何もせず閉じない
- **メモそのものは消さない。** 同じ話が繰り返し流れることを、後から比べられる

## 止まるところ

- **人間が書いた評価を塗り替えるとき。** 前の見方と新しい見方を並べて、更新してよいかを聞く
- **`horse_notes` を書くとき。** 対話で決めると決めてある
- メモの意味が読み取れないとき。**推測で宛先を決めない**
