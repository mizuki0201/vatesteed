# タスク管理

タスクは **`docs/tasks/` 配下に1タスク1ファイル**で置く。フラットに並べ、分類は frontmatter で持つ。

`docs/tasks/` は **gitignore してある**（コミットしない）。手元だけの作業リストなので、ここに書いた
内容が他の人に共有されることは無い。**逆に、消えたら復元できない**（git 履歴に残らない）ので、
ファイルを消すときは必ず確認を取る。

ディレクトリが無ければ `mkdir -p docs/tasks` で作ってから始める。

## ファイルの形

ファイル名はタイトルを英小文字のケバブケースにしたもの（`race-name-alias-master.md` など）。
連番は付けない。

```md
---
title: レース名の別名マスタを作る
area: lib
status: todo
created: 2026-08-09
updated: 2026-08-09
---

## なぜ

この作業が必要になった理由。会話の中で出てきたなら、そのときの経緯をここに残す。

## 完了条件

- [ ] 何ができたらこのタスクを閉じるか。チェックボックスで並べる

## メモ

- 2026-08-09 進捗や判断をここに追記していく

## 参照

- docs/agent-design.md — 関連する設計上の記述
```

### frontmatter

| キー | 中身 |
| --- | --- |
| `title` | 日本語のタイトル。ファイル名と対応させる |
| `area` | 責務・領域。`agent` `app` `lib` `db` `docs` `ops` など（**例示であって網羅ではない**。当てはまるものが無ければ新しく付けてよい） |
| `status` | `todo` / `doing` / `blocked` / `done` のどれか |
| `created` | 起票した日 |
| `updated` | 最後に中身を触った日。**触ったら必ず更新する** |

`status: blocked` のときは、frontmatter に `blocked_by:` を足して何待ちかを1行で書く。動けるように
なったら消す。

## 依頼別の手順

### 一覧を見せる

frontmatter だけをまとめて読む。

```bash
grep -H "^title:\|^area:\|^status:" docs/tasks/*.md
```

読んだら `status` ごとにまとめて口頭で伝える。ファイルの中身をそのまま貼り付けない。`done` は
聞かれたときだけ出す。領域を指定されたら `area` で絞る。

### 起票する

1. `docs/tasks/` を見て、**同じ内容のタスクが既に無いか確かめる**。近いものがあれば新しく作らず、
   そのタスクに書き足していいか確認する
2. 「なぜ」と「完了条件」を埋める。依頼の文面から埋まらない部分は推測で埋めず、本人に聞く
3. `area` を決める。またがるときは主なほうを選び、もう一方は「参照」に書く
4. `status: todo` で作る。すぐ着手すると分かっているときだけ `doing` にする

### 内容を更新する / ステータスを変える

**言われたときだけでなく、会話の中で状況が変わったら自分から更新する。**

- 着手した → `status: doing`
- 何かを待つことになった → `status: blocked` + `blocked_by:`
- 完了条件の一部が終わった → 該当するチェックボックスを `- [x]` にする
- 判断や方針が決まった → 「メモ」に日付付きで1行足す
- 前提が変わって完了条件そのものが変わった → 「完了条件」を書き換え、「メモ」に変えた理由を残す

どれをやっても `updated` を実行日にする。**更新したことは必ず報告する**（黙って書き換えない）。

### 完了にする

1. 完了条件のチェックボックスが全部 `- [x]` になっているか確認する。**残っているのに閉じない**
2. `status: done` にし、`updated` を実行日にする
3. ファイルは `docs/tasks/` に置いたまま。**移動も削除もしない**

### 設計の「未確定事項」を持ち込まれたとき

`docs/` に「未確定」と書かれているものは、決めるべき問いであって作業ではない。**そのままタスクに
しない。** 「これは `docs/` 側の未確定事項なので、決めるところから始める」と伝える。決めた結果と
して手を動かす作業が出てきたら、そのときタスクに切る。

## 守ること

- **日付は実行日を使う。** 分からなければ `date +%F` で確認する。推測で書かない
- **依頼されたタスクだけを触る。** ついでに他のタスクを整えたり、気づいた作業を勝手に起票したり
  しない。起票したほうがよさそうなものを見つけたら、切っていいかを聞く
- **タスクファイルを消さない。** 不要になったものは `status` を `done` にするか、消していいかを聞く
- **コミットしない。** `docs/tasks/` は gitignore 済みなので、そもそもコミット対象に入らない
