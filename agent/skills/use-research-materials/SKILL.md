# 調査資料を使う

情報を集める役、分析する役、文章を確認する役は固定しない。1つのエージェントがすべてを担っても、
複数のエージェントで分けてもよい。分析する役は、まず渡された調査資料と DB を材料に、登録・
分析・予想を行う。材料不足が判断に効くときだけ、不足した事実を確かめる範囲で外部サイトや動画を
探してよい。

**Phase 1 では Codex が収集と文章確認、Claude Code が分析を担う形をまず試す。** これは現在の
運用であって固定しない。資料の受け渡し方や担当は、精度と使いやすさを見て都度変える。Codex と
Claude Code のどちらかだけで進めることや、逆の配置もできる。

## 受け取る資料

調査資料には、少なくとも次の情報があるかを確かめる。

- 何を確かめるために集めたか
- 出典と確認時点
- 確認できた事実
- 動画なら該当時点、話者、発言か映像で確認したことか
- 情報源どうしで食い違う点
- 取れなかった情報

ページや動画の本文をそのまま DB へ残さない。登録するのは、競馬の事実として必要な要約だけである。
発言、映像で確認したこと、そこからの読みを混ぜない。

## 進め方

1. まず DB と調査資料を読み、登録すべき事実と分析に使う材料を分ける。
2. 必要な事実を登録してから、対象に合う分析する役を呼ぶ。
3. 評価と予想を作ったら、検証する役で根拠のつながりを確かめる。
4. 材料不足や食い違いが判断に効くなら、必要な情報を資料の作成者へ返す。自分で確認する必要がある
   場合は、対象・確かめる事実・必要な判断を先に定め、その範囲だけを見る。

資料の作成者へ返すときは、「情報が足りない」とだけ書かない。対象、確かめたい内容、その情報が
どの判断に必要かを1件ずつ示す。Claude Code が確認した情報も、出典、確認時点、確認できた事実、
食い違いを添える。ページ本文や動画の書き起こしは渡さない。

## 最後の文章確認

登録する本文や人間へ返す文は、文章確認を担う役の確認を通す。確認するのは、造語、不自然な
比喩、根拠より強い断定、事実と読み取りの混同、競馬の話として読めない表現である。

指摘があれば、分析を担った役が直す。文章確認を担う役は、評価・印・買い目を決めたり、文章を
直接書き換えたりしない。
