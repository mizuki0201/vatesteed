# エージェント設計

> **このドキュメントは大部分が未確定。** 引き継ぎ資料の時点で「最も手つかず」の領域。
> 下の内容を確定として扱わないこと。

## 前提（確定）

- skills は `agent/skills/` に置き、eve の `SKILL.md` 規約に従う（Agent Skills 標準と互換）
- skills はエージェント単位でスコープされる。subagent の skills はルートから見えず、逆も同じ。
  共有したい実行コードは `lib/` に置く
- `agent/instructions.md` は常時読み込み。短く安定した内容（identity と standing rule）だけに
  保ち、長い手順や状況依存の手順は skills に置く

## 機能領域（暫定案）

**分割粒度ごと見直す前提の暫定案。この単位でサブエージェントや skill を切ると決めたわけでは
ない。**

- 各馬の過去走を1走ずつ、内容・展開・不利・相手関係を踏まえて評価する
- ローテーション・調整過程・輸送や遠征の影響を評価する
- 相手関係からレースレベルを推定する
- 適性（距離・馬場・コース）を見立てる
- それらを統合して能力値・評価に変換する
- 騎手・陣営のレース後コメントを蓄積し、含意を読み取って評価に反映する

再現したい思考の全体像は [concept.md](concept.md#再現したい思考の範囲) を参照。
そこにも書いたとおり、列挙は例示であって網羅ではない。
