# 馬・血統・出走の分析品質

馬の総合分析、血統分析、1つの出走の分析について、本文を作るときの観点、構成、必要な深さ、
書かない内容を定める。対象が変わっても同じ判断のしかたを使えるようにするための正本である。

## 共通の原則

- 着順、時計、人気、血統表など、表示されている事実を並べ直して終わらない。事実を根拠として、
  対象について何が言えるのかまで書く
- 事実と読み取りは同じ文章にまとめてよいが、どの事実から何を読んだのかを追える形にする
- 根拠より広い結論へ進まない。1つの出走で確認した内容、複数の出走で繰り返した性質、
  一時的な状態を分ける
- 結論を変えうる反対の材料と別の説明を探し、都合のよい材料だけで決めない
- 必要な情報を入れ切ることを文字数より優先する。文字数は、短い要約へ縮めて材料を落として
  いないかを見直す目安であり、完成条件でも上限でもない
- 書く材料が無い観点を、推測、一般論、同じ意味の言い直しで埋めない
- 評価の本文には、調査方法、保存先、役の分担、取得できなかったサイトなど、競馬の分析ではない
  作業の説明を書かない

## 馬の総合分析

### 観点

1頭の全出走と各出走の評価、血統評価、関係者の発言、人間から渡された観察を合わせ、次を検討する。

- 概要
- 馬の特徴
- 脚質
- 距離適性
- 馬場適性
- 競馬場・コース適性
- 展開による得意不得意・向き不向き
- 能力面
- 気性・精神面
- 実績による裏付け
- 成長・変化
- その他特筆点

この一覧は、馬について検討する観点として使う。本文へ置く見出しは、根拠のある内容があるものだけに
する。根拠が無い項目を「不明」「未確認」などで埋めない。

### 構成

- `## 概要` を最初に置き、各項目の結論を短く統合する
- それ以降は、上の観点のうち材料があるものを `##` の見出しとして置く
- 「馬の特徴」には複数の条件や出走で繰り返された性質を書く。1日だけ起きた出来事を書かない
- 「脚質」は位置取り、発馬、動き始める地点、選べる戦法を扱う。「展開」は流れ、隊列、
  他馬の動きとの関係を扱い、同じ内容を両方に書かない
- 「能力面」は加速、速さ、速さを保つ力、持久力など、何ができるかを書く。「実績による裏付け」は
  相手の水準、負担重量、異なる条件で何が確認されたかを書く
- 「成長・変化」には競走生活の中で変わった能力、脚質、気性、身体面を書く。当日だけの状態は残さない
- 「その他特筆点」は、ほかの項目に入らない重要な内容に限る

### 必要な深さと分量

- 全出走を読み、勝った出走だけでなく、敗れた出走、力を出せなかった出走、異なる条件の出走も
  同じように検討する
- 複数の出走で繰り返した内容は、反対の出走が無いかを確認してから性質として書く
- 距離、馬場、競馬場、回り、コースの形、展開、負担重量、相手の水準を分け、どの違いが結論を
  変えるのかを確かめる
- 血統から読める素地と実績を突き合わせる。実績で確認できたことを、血統の根拠としてもう一度
  数えない
- 個別の出走や血統の詳細は、総合評価の根拠として欠かせない代表例だけを書く
- ディープインパクトのように競走生活全体の材料が揃う馬では、2,000文字程度を下回ったら、
  上の観点や反対の材料を落としていないか読み直す。材料が少ない馬をこの文字数へ合わせず、
  特筆点が残る馬には上限を設けない

### 書かない内容

- 確認していない条件の推測や、確認していないことの一覧
- 各出走の振り返りや血統評価の全文を並べ直したもの
- 同じ結論や根拠を複数の項目で繰り返したもの
- 一時的な状態を、その馬に常に当てはまる特徴としたもの
- 「万能」「最強」など、比較する対象と基準が定まらない評価

## 血統分析

### 観点

対象馬自身の実績を使わず、血統だけから適性の素地を読む。少なくとも次を検討し、材料があれば
この一覧に無い観点も足す。

- 母自身と牝系
- 父の子の傾向
- 母父と配合
- 系統とクロス
- 距離
- 速さの出し方
- 位置取り
- 馬場
- コースの形
- 気性
- 成長の型
- 体質

### 構成

本文の既定の見出しは、`概要 / 母と牝系 / 産駒の傾向 / 母父と配合 / 系統とクロス /
適性の素地` とする。血統の材料を説明する前半と、それらを適性へ結び付ける「適性の素地」を分ける。
調べた範囲、世代、対象にした父の子や近親の数、対象馬を除いた数は `scope` に書き、本文へ
調査の説明として混ぜない。

### 必要な深さと分量

- 父系と母系を5〜6代までたどる
- 母、きょうだい、近親、父の子、母父の子を同じ材料として混ぜず、それぞれの近さと件数を示す
- 勝ち鞍の数だけで傾向を決めず、出走した条件の偏りと母数を確認する
- 距離だけで終わらず、速さの出し方、位置取り、馬場、コースの形、気性、成長の型、体質まで、
  材料のある範囲を検討する
- 適性は、血統のどこからそう言えるのかと一緒に書き、どの結果が出れば読みが違ったと分かる
  具体さを持たせる
- 5〜6代、近親、父の子まで十分な材料が取れた場合は、4,000文字程度を、短い一般論や血統表の
  言い直しで終わっていないかを読み直す目安にする。材料が少ない血統をこの文字数へ合わせず、
  特筆点が残る場合は上限を設けない

### 書かない内容

- 対象馬自身の出走結果や能力評価
- 対象馬自身の実績を含めた父の子の傾向
- 母の子を、父の「産駒の傾向」としてまとめたもの
- 件数が少ない組み合わせを、血統全体の性質へ広げたもの
- 血量だけを根拠にした能力評価
- 出典のサイト名、取得の成否、今回のレースに合わせた買い方

血統分析では、調べた範囲と読みの限界を区別するために、材料が無いこと自体を書く場合がある。
ただし、材料が無いことを「向かない」根拠にしたり、別の材料にある直接的な根拠を弱めたりしない。

## 1つの出走の分析

### 観点

1頭が1つのレースで経験した内容だけを扱い、次を必要な範囲で検討する。

- 競馬場、芝・ダート、距離、回り、馬場状態、天気、頭数、格、負担重量、枠番と馬番
- ラップと流れが変わった区間
- 各コーナーの位置と、位置が変わった区間
- 同じ展開の助けや不利を受けた相手との比較
- 余計に使った脚、進路、接触、発馬、折り合いなど、結果の数字に直接出ない負荷
- 上がり、着差、走破時計が生まれた過程
- 相手の当時までの実績と、その後の実績で補強できる相手の水準
- 人間から渡された映像の観察と、関係者が述べた内容

### 構成

見出しや材料の個数は固定しない。条件と起きたことを押さえ、流れと位置の関係、相手との比較、
結果の数字とのずれが、根拠から結論まで一続きで読める順に書く。事実を列挙したあとに短い結論を
付ける形ではなく、事実が評価へどう効いたかを各段落で示す。

### 必要な深さと分量

- 数字を見る前に何が起きたかを組み立て、最後に着順、時計、上がりと突き合わせる
- 通過順から言えない進路や騎手の意図は、映像の観察や発言があるときだけ使う
- 展開の助けや不利は、同じ条件を受けた馬と比べ、対象馬だけに都合よく割り当てない
- 1つの出走で確認した内容を、その馬に常に当てはまる性質へ広げない
- 700文字程度を下回ったら、ラップ、位置、相手比較、負荷、着差、人間の観察から、判断に使った
  材料を落としていないか読み直す。700文字は完成条件でも上限でもなく、材料が乏しければ短く、
  特筆点があれば必要な分だけ書く

### 書かない内容

- 前後の出走を総合して作った馬の性質
- 人間が明示していない、次の出走での扱いや買い方
- 分からなかったこと、経験していない条件、今回取らなかった戦法の一覧
- 着順、時計、通過順など、表示されている数字の言い直しだけの段落
- 固定した個数へ合わせるために足した材料、推測、重複
- 結果に合う説明だけを選び、結論を変えうる別の説明を落とした文章

## ディープインパクトを参考例として使う

次の固定した文章を、3種類の分析に対応する参考例とする。分析を始めるときは、担当する種類の
一般ルールと参考例を両方読む。

| 分析 | 参考例 |
| --- | --- |
| 馬の総合分析 | `agent/reference-examples/deep-impact/horse.md` |
| 血統分析 | `agent/reference-examples/deep-impact/pedigree.md` |
| 1つの出走の分析 | `agent/reference-examples/deep-impact/entries.md` |

参考にするのは、次の3点である。

- どの観点まで検討しているか
- 事実、比較、読み取り、結論をどうつないでいるか
- 材料の量に応じて、どの程度の情報を残しているか

**ディープインパクトについて書かれた結論、事実、評価、文章表現を、別の馬へ移してはならない。**
見出し、段落数、文字数も同じにそろえない。対象の材料から出る分析を先に作り、参考例と比べて
観点の欠落、根拠の飛躍、短い要約への縮小が無いかを確認する。
一般ルールと参考例の書き方が異なる場合は、一般ルールを優先する。参考例の古い書き方を、固定した
文章のまま新しい分析へ引き継がない。

参考例は、2026年9月8日時点でDBに保存されていた本文を固定したものである。分析のたびにDBから
取得せず、DBの本文が変わっても自動では書き換えない。本人から参考例自体を変更する指示があった
場合だけ、固定した文章を更新する。
