# 法務・コンプライアンス

## 確定している方針

- **JRA-VAN は商用利用不可。**
- スクレイピングの論点は3層に分けて考える
  1. **取得行為** — 各サイトの利用規約
  2. **蓄積・解析** — 著作権法30条の4
  3. **出力・販売** — 引用要件
- **採用方針: 自分の目で見て、自分の言葉で要約・評価した内容をナレッジに登録する**
  - 規約・著作権どちらの論点も薄くなる
  - 副産物として「自分のフィルターを通した解釈」が蓄積され、コンセプトとも合致する
- 販売時は**景品表示法**（回収率の誇大表示）にも注意する
