# decisions

個別の決定記録。

各ドキュメントには「今どうなっているか」を書く。ここには「なぜそう決めたか」を残す。
後から見て理由が思い出せないと困る決定、あるいは一度検討して見送った選択肢がある決定だけを
記録する。すべての決定を書く必要はない。

## 書き方

ファイル名は `NNNN-短い題名.md`（例: `0001-package-manager.md`）。

```markdown
# 短い題名

- 日付:
- 状態: 採用 / 見送り / 置き換え済み（→ 置き換え先へのリンク）

## 背景

## 決定

## 検討したが採らなかった案

## 影響
```

この形式は暫定。運用してみて合わなければ変える。
